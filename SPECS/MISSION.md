# Mission

## Purpose

Build a stadium security dashboard that prevents data loss during investigations.

Detectives need to track entry logs reliably. When a server crashes mid-game, the data must survive so investigations can continue. This project solves that problem.

## Who It's For

Students learning web development. They know basic Python, HTML, CSS, and a little JavaScript, but are not experts yet.

## Success Looks Like

- A working dashboard that shows stadium entry logs
- Data persists in SQLite even if the server crashes
- Detectives can filter entries by gate to find specific people

## Values

- **Simplicity** — code that beginners can read and understand
- **Data safety** — nothing gets lost when things go wrong
- **Clean separation** — frontend, backend, and database each do one job

## Out of Scope

- User accounts or login
- Real-time alerts
- Multi-user access
- Data export (CSV/JSON)
